## Power BI Dashboard

This project includes a Power BI dashboard built from a synthetic supplier-delivery dataset. The dashboard analyzes promised vs. actual delivery dates, late deliverables, average delay, and supplier reliability trends.

Dashboard features:
- KPI cards for total deliverables, late deliverables, average delay, and on-time delivery rate
- Supplier reliability comparison
- Monthly delivery performance trend
- Filters by supplier, status, and month
