## Power BI Dashboard

This project includes a Power BI dashboard built from a synthetic supplier-delivery dataset. The dashboard analyzes promised vs. actual delivery dates, late deliverables, average delay, delivery cost, and supplier reliability trends.

Dashboard features:
- KPI cards for total deliverables, late deliverables, average delay, worst delay, and on-time deliverables
- Supplier reliability comparison
- Monthly delivery performance trend
- Delivery status breakdown
- Filters by supplier, status, and month
